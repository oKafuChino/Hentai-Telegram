# Hentai-Telegram Bot 指令说明

本机器人专为管理和向 Telegram 频道发布漫画而设计。

> ⚠️ **所有指令仅限 `.env` 中配置在 `TELEGRAM_ALLOWED_USER_IDS` 的管理员使用**。非管理员发送消息将被拦截并提示无权使用。

---

## 常用指令列表

| 指令 | 作用 | 示例 |
| :--- | :--- | :--- |
| `/start` 或 `/help` | 查看机器人欢迎信息与指令帮助 | `/start` |
| `/jm <ID或链接>` | 抓取禁漫漫画，上传至 Telegraph 并发布到指定 Telegram 频道 | `/jm 123456` |
| **直接发送数字 ID 或链接** | 在管理员与机器人的私聊中直接发送纯数字 ID 或链接，自动识别入队 | `123456` |
| `/tasks` | 列出当前正在下载、正在上传或排队中的任务，附带快捷取消按钮 | `/tasks` |
| `/cancel <任务ID>` | 取消正在进行或排队中的任务 | `/cancel a1b2c3d4` |
| `/retry <任务ID>` | 重新排队重试失败的任务 | `/retry a1b2c3d4` |
| `/channel` | 检查并验证目标 Telegram 频道配置及 Bot 发帖管理员权限 | `/channel` |
| `/status` | 查看服务运行时长、Worker 状态、缓存磁盘与任务统计 | `/status` |
| `/logs` | 获取最近 100 条系统运行日志（敏感信息自动脱敏） | `/logs` |

---

## 任务执行与频道发布规则

1. **下发与响应**：
   - 管理员发送 `/jm <ID>` 或直接发送 ID 后，Bot 会立即回复一条任务进度消息。
   - 该消息会随着后台处理实时原地编辑更新状态：
     1. `[1/4] 正在下载图片... (章节 1/2, 10/30 页)`
     2. `[2/4] 正在上传 Telegraph... (章节 1/2, 15/30 页)`
     3. `[3/4] 正在生成全本目录页面...`
     4. `[4/4] 正在发布到 Telegram 频道...`
     5. `✅ 已成功发布到频道！[点击查看频道推文]`

2. **频道消息格式**：
   - 携带首章首页作为封面图片。
   - 包含漫画标题、作者、标签、JM 编号。
   - 提供各章节的 Telegraph 阅读链接（支持 Telegram Instant View 即时预览）。
   - 若漫画为多章节，会自动在 Telegraph 上生成目录索引页，并提供便捷内联按钮。
